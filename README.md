# DUMMY ENG – English Communication Landing Page

A Small Website Design Project

## Project Overview

Dummy Eng is a small landing page project for an English communication learning initiative.

The website introduces the project and presents its information through a simple, approachable landing page.

## Project Objectives

- Establish a clear online presence for Dummy Eng.
- Present the English learning offering.
- Create a friendly and approachable visual experience.
- Organize website content in an accessible format.

## Design Deliverables

- Landing Page Design
- Website Layout
- Visual Branding
- Website Screenshots
